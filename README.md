# Horizon | Weather Intelligence

Horizon is a modern, lightweight weather application built with Vanilla JS. It features a stunning glassmorphism UI and utilizes the **Open-Meteo API** to provide accurate real-time weather data and forecasts without requiring any API keys or configuration.

## 🌟 Features

- **Zero-Config Setup**: Powered by Open-Meteo, so no API keys are needed. Just clone and run.
- **Glassmorphism Design**: A premium, frosted-glass aesthetic that adapts to weather conditions.
- **Dynamic Backgrounds**: The interface changes color and theme based on the current weather (Clear, Cloudy, Rainy, etc.).
- **Detailed Metrics**: View temperature, humidity, wind speed, pressure, and visibility at a glance.
- **5-Day Forecast**: Predictive modeling for the week ahead.
- **Geolocation**: One-click local weather fetching.

## 🛠️ Tech Stack

- **HTML5 & CSS3**: Semantic structure with advanced CSS animations and variables.
- **Vanilla JavaScript (ES6+)**: tailored logic for asynchronous data fetching and DOM manipulation.
- **Open-Meteo API**: Free, open-source weather data provider.

    ```bash
    git clone https://github.com/yourusername/horizon-weather.git
    ```
2.  **Open the project**
    Navigate to the folder and open `index.html` in your browser.
    ```bash
    cd horizon-weather
    # Open index.html manually or use a simple server
    ```

3.  **Enjoy!**
    Search for any city or use your current location to see the magic happen.
